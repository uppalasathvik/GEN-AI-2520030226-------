# Scaled Dot-Product Attention and Multi-Head Attention

Implementation of Scaled Dot-Product Attention and Multi-Head Attention from scratch using PyTorch.

## Files

- `main.py` — Implements `scaled_dot_product_attention` (with optional causal masking) and `MultiHeadAttention`, along with sample tensor tests.
- `requirements.txt` — Python dependencies (`torch`).

## Setup & Run

```bash
pip install -r requirements.txt
python main.py
```
